08-relative-units

Specify a length relative to another length property.

  • Pxel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport Units Horizontal (vh)
  • Viewport Units Width (vw)
  • Largue viewport (lvh|lvw)
  • small Viewport (svh|svw)
  • Dinamic Viewport (dvh|dvW)

Examples

  • Pixel: 32px
  • M: 1em
  • Root M: 1.rem
  • x: 2ex
