01-Emmet

Plugin para codificación más rápida en HTML y CSS.

01-Child >

Create child elements (nesting).

Example:

ul>li>a↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling +

Create sibling elements.

Example:

header+section+footer↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeat elements multiple times.

Example:

ul>li*3↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class .

Create a class atribute

Example:

div.important↔️

.danger↔️

Result:

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Create multiples classes atributes

Example:

div.red.green.blue

Result:

<div class="red green blue"></div>

06-Identification or ID #

Create an ID atribute

Example:

menu#cod123

Result:

<menu id="cod123"></menu>

07-Text {}

Insert text content

Example:

p{lorem ipsum dolor} ↔️

a{Click here}

Result:

<p>lorem ipsum dolor</p> <a href="">Click here</a>

08-Custom Attribute {}

Creates custom attributes.
